# T-GPS

Tesla 차량과 **블루투스(BLE)로 직접 통신**해 차량의 현재 위치를 읽고, 그 위치를 기준으로 **폰의 GPS 위치를 지정한 좌표로 임시 고정(모의 위치)** 하는 안드로이드 앱입니다.
GPS 신호가 없는 지하주차장 등에서 폰 위치가 필요한 기능을 쓸 때를 위해 만든 개인 프로젝트입니다.

- Tesla 계정 로그인, Tesla Fleet API, 별도 서버가 **필요 없습니다.**
- 앱에 **인터넷 권한이 없습니다.** 어떤 데이터도 외부로 전송하지 않습니다.
- Kotlin + Jetpack Compose, 다크 테마.

> ⚠️ **비공식 프로젝트입니다.** Tesla, Inc.와 무관하며 후원·승인을 받지 않았습니다. "Tesla"는 Tesla, Inc.의 상표입니다.
> 반드시 아래 [면책 및 주의사항](#면책-및-주의사항)을 읽고 사용하세요.

## 주요 기능

- **BLE 위치 조회** — 차량이 절전 중이면 BLE로 깨운 뒤 위도·경도·방향(heading)을 읽음
- **위치 지정(앵커)** — 차량 기준 전후·좌우 오프셋을 정해 폰 위치를 그 좌표로 고정하고, 종료하면 실제 GPS로 복구
- **자동 복구 타이머**, 알림에서 바로 종료
- **차량 기준 위치 그림** — 오프셋을 눈으로 확인하며 조정
- **페어링 도우미** — VIN 입력, 키 등록 요청, 등록 확인

## 동작 방식

1. VIN으로 차량의 BLE 광고 이름을 계산(`S` + SHA-1(VIN) 앞 8바이트 hex + `C`)해 차량을 찾아 GATT 연결
2. VCSEC 상태 조회 → 절전이면 BLE로 깨우기
3. 인포테인먼트 세션 수립(P-256 ECDH → 세션 키, AES-GCM 암호화) 후 `GetVehicleData(location)` 요청
4. 받은 좌표·방향으로 폰의 목표 좌표를 계산해 Android 모의 위치(테스트 프로바이더)로 주입

프로토콜 구현은 Tesla가 공개한 [vehicle-command](https://github.com/teslamotors/vehicle-command)(Apache-2.0)를 참고해 Kotlin으로 옮긴 것입니다 (`tesla/`).

## 요구사항

- Android 8.0(API 26) 이상, BLE 지원 기기
- BLE 프로토콜을 지원하는 Tesla 차량 (펌웨어에 따라 동작이 다를 수 있음)
- 개발자 옵션의 **모의 위치 앱**으로 T-GPS를 지정할 수 있어야 함
- 차량에 키를 등록하기 위한 **NFC 키카드**

## 빌드

Android Studio(JDK 17)로 열어 빌드하거나, 이 저장소의 GitHub Actions(`.github/workflows/build.yml`)로 디버그 APK를 만들 수 있습니다.

```bash
gradle :app:assembleDebug     # Gradle 8.10.x
```

## 사용법

### 처음 한 번: 차량에 키 등록(페어링)

1. 폰의 **개발자 옵션 → 모의 위치 앱 선택 → T-GPS**
2. 앱을 실행하고 위치·근처 기기(블루투스)·알림 권한을 허용
3. 설정 팝업에 **VIN(17자리)** 입력
4. 차 화면이 켜진 상태에서 **① 페어링 요청 보내기**를 누르고, **바로(약 35초 이내)** 센터콘솔의 NFC 카드 리더에 키카드를 댐
   - 차량은 요청을 받아도 **아무 반응이 없는 것이 정상**입니다.
   - 카드를 대면 차량 화면에 **확인(Confirm)** 이 뜨고, 누르면 등록이 끝납니다.
5. 앱이 자동으로 등록을 확인한 뒤 차량 위치를 조회합니다. (수동 확인은 **페어링 확인** 버튼)

키 역할은 기본 **Driver**입니다. 위치 조회에서 권한 부족 오류가 나면 설정에서 Owner로 바꾸고 **키 새로 만들기 → 다시 페어링**하세요.

### 평소 사용

1. 차량 가까이(블루투스 범위)에서 앱을 열어 차량 위치를 조회
2. 오프셋(전/후, 좌/우)을 조정하고 **시작** — 폰 위치가 지정 좌표로 고정됨
3. 끝나면 **사용 종료** (또는 알림의 종료 버튼, 자동 복구 타이머) — 실제 GPS로 복구

## 보안 및 개인정보

- 네트워크 권한이 없어 **외부로 데이터가 전송되지 않습니다.**
- 페어링 **개인키**는 `EncryptedSharedPreferences`(AES-256)에 저장되며 앱 밖으로 내보내는 기능이 없습니다. 백업에서도 제외됩니다(`allowBackup=false`).
- VIN과 설정은 기기 내부 저장소에만 저장됩니다.
- 앱 내부에 오류 기록 파일(`filesDir/diag.log`, 약 200KB 상한)이 남습니다. VIN은 끝 6자리만 기록하고 개인키는 기록하지 않습니다. 화면에서 볼 수 있는 메뉴는 없으며, 앱을 삭제하면 함께 지워집니다.
- 등록된 키는 **이 앱에서만** 쓸 수 있습니다. 앱을 삭제하거나 데이터를 지우면 개인키가 사라지며, 차량에는 쓸 수 없는 키가 남으므로 차량 화면의 잠금 메뉴에서 삭제하세요.
- 이슈나 PR에 로그·스크린샷을 올릴 때는 **VIN 전체, 키 지문, 좌표(집·주차장 위치)** 가 포함되어 있지 않은지 확인하세요.

## 한계

- 차량이 BLE 연결 슬롯 3개를 이미 사용 중이면(폰키·키카드 등) 연결이 밀릴 수 있습니다.
- 차량이 방향(heading) 값을 주지 않으면 북쪽 기준으로 계산하며, 이 경우 전·후방이 틀릴 수 있습니다.
- 위치 조회 시 절전 중인 차량이 깨어납니다. 반복 호출은 피하세요.
- 차량 펌웨어 변경으로 동작이 달라질 수 있습니다. 모든 차종·펌웨어에서 검증되지 않았습니다.

## 면책 및 주의사항

- 이 앱은 **폰의 위치 정보를 실제와 다르게 표시**합니다. 그로 인해 발생하는 모든 결과와 법적 책임은 사용자 본인에게 있습니다.
- 차량을 원격으로 움직이는 기능(예: 차량호출)과 함께 쓸 경우, **차량을 직접 눈으로 보며** 해당 기능의 제조사 안내와 관련 법규를 준수해야 합니다. 이 앱은 그런 안전 요건을 우회하기 위한 도구가 아닙니다.
- 본인 소유(또는 명시적 허가를 받은) 차량에만 사용하세요.
- 소프트웨어는 **있는 그대로(AS IS)** 제공되며 어떠한 보증도 없습니다. 사용으로 인한 차량 손상, 사고, 계정·보증 문제 등에 대해 작성자는 책임지지 않습니다.
- Tesla의 서비스 약관·보증 조건은 변경될 수 있으니 사용 전 직접 확인하세요.

## 프로젝트 구조

```
tesla/Wire.kt          최소 protobuf 인코더/디코더
tesla/Crypto.kt        메타데이터 해시, ECDH, 세션(AES-GCM/HMAC)
tesla/Messages.kt      RoutableMessage / VCSEC / CarServer 메시지, 위치 파싱
tesla/VehicleClient.kt 상태 조회·페어링·깨우기·핸드셰이크·위치 읽기
ble/Ble.kt             차량 스캔 + GATT 전송(2바이트 길이 헤더, MTU 분할)
core/                  오프셋 계산, 모의 위치 주입, 포그라운드 서비스
data/Prefs.kt          BLE 키·VIN·설정 저장
diag/DiagLog.kt        내부 오류 기록(파일)
ui/                    Compose 화면, 차량 위치 그림, 테마
```
